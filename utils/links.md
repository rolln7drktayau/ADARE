# Sources des benchmarks

Les liens suivants ont permis d'obtenir les benchmarks chargés dans le dossier `data/workflows`:

- <https://github.com/maomao0217/Scientific-Workflow-Visualization>
- <https://pegasus.isi.edu/workflow_gallery/>

Ces ressources fournissent des workflows scientifiques au format XML qui ont été utilisés comme données d'entrée pour les tests de performance d'ADARE.
